# Feature of Sattvik Bhojan Console application 
| S.No | Feature | Description |
|---|---|---|
| 1 | Admin/Staff Login | Allows authorized staff to access the system |
| 2 | Role-Based Access | Controls what different users can do |
| 3 | Food Menu Management | Add, view, update and delete food items |
| 4 | Customer Management | Add, view, update and search customer details |
| 5 | Order Management | Create and manage customer orders |
| 6 | Order Status Tracking | Track orders as Pending, Preparing, Completed or Cancelled |
| 7 | Order Details | Store multiple food items and quantities in each order |
| 8 | Price Calculation | Automatically calculate the total order amount |
| 9 | Search | Search customers, food items and orders |
| 10 | Sales Summary | Display total orders, revenue and order statistics |
| 11 | Database Storage | Store application data permanently in PostgreSQL |
| 12 | Exception Handling | Handle invalid input and database errors |
| 13 | Logout | Safely end the current user session |
